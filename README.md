# Features

Render Polygons

Keyboard and Mouse movement

# Requirements

vcpkg

OpenGL

glm

glew

glfw3

# Building

Clone the repository.

Open the .sln file.

Install dependencies using vcpkg manifest integration.

Select x64 and Release.

Build the project.
